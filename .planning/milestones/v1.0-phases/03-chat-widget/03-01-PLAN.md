<task type="auto">
  <name>Task 2: Create useChatApi hook with SSE stream parsing</name>
  <files>src/hooks/useChatApi.js</files>
  <action>
Create `src/hooks/useChatApi.js` with the following:

1. **Import SYSTEM_MESSAGE** from `@/data/chatPrompt` (using path alias).

2. **PROXY_URL constant:**
   ```javascript
   const PROXY_URL = import.meta.env.VITE_PROXY_URL;
   ```

3. **useChatApi(dispatch) hook:**
   - Accepts `dispatch` function from useReducer
   - Creates `abortRef = useRef(null)` to track AbortController
   - Returns `{ sendMessage, abort }`

4. **sendMessage(messages) function** (wrapped in useCallback with [dispatch] dependency):
   - Abort any in-flight request: `abortRef.current?.abort()`
   - Create new AbortController: `abortRef.current = new AbortController()`
   - Generate bot message ID: `const botMessageId = crypto.randomUUID()`
   - Dispatch `START_BOT_MESSAGE` with the generated ID
   - Call `fetch(PROXY_URL, { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ messages: [SYSTEM_MESSAGE, ...messages.map(m => ({ role: m.role, content: m.content }))] }), signal: abortRef.current.signal })`
   - If `!response.ok`: throw Error with status
   - Get reader: `response.body.getReader()`
   - Create decoder: `new TextDecoder()`
   - Maintain buffer string for partial lines
   - **Stream parsing loop:**
     ```
     while (true):
       read from reader
       if done, break
       append decoded value to buffer (with stream: true option)
       split buffer on '\n'
       keep last element as new buffer (may be incomplete)
       for each complete line:
         trim whitespace
         skip if empty or doesn't start with 'data: '
         extract data after 'data: ' prefix
         if data === '[DONE]', dispatch STREAM_COMPLETE and return
         try JSON.parse, extract choices[0].delta.content
         if token exists, dispatch APPEND_TOKEN with id and token
         catch: skip malformed JSON silently
     ```
   - After loop exits (reader done without [DONE]): dispatch `STREAM_COMPLETE`
   - **Error handling (catch block):**
     - If `err.name === 'AbortError'`: ignore (intentional cancellation)
     - Otherwise: dispatch `SET_ERROR` with message "Oops, something went wrong. Please try again."

5. **abort() function** (wrapped in useCallback with [] dependency):
   - Calls `abortRef.current?.abort()`

**Critical implementation notes:**
- Do NOT put `[DONE]` handling in a separate branch — it must be checked before JSON.parse
- Use `{ stream: true }` option in TextDecoder.decode() to handle multi-byte characters at chunk boundaries
- The SYSTEM_MESSAGE is prepended to messages at call time, NOT stored in reducer state
- Only map `role` and `content` from messages — strip any extra fields (id, isError, isLimit)
