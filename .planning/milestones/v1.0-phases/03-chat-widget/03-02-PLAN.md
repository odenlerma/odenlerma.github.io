  - visible: `{ opacity: 1, scale: 1, y: 0, transition: { type: 'spring', damping: 25, stiffness: 300 } }`
  - exit: `{ opacity: 0, scale: 0.85, y: 20, transition: { duration: 0.2 } }`
- Contains: ChatHeader, MessageList, ChatInput (composed vertically in flex column)
- On mount (first open): if messages are empty, dispatch `ADD_SYSTEM_MESSAGE` with welcome message: "Hi! I'm Audy, Audruey's AI assistant. Ask me anything about her experience, skills, or projects." (id: `'welcome'`, isLimit: false)

- Display "Audy" as bot name with a small bot icon (use `bi-robot` from bootstrap-icons)
- Close button on the right: `bi-x-lg` icon
- On close click: `dispatch({ type: 'SET_OPEN', payload: false })` and call `abort()` to cancel any in-flight stream
- Styled with slightly lighter background than panel body

**4. MessageList.jsx** — Scrollable message container
- Render array of MessageBubble components from `state.messages`
- Show TypingIndicator when `state.isStreaming` AND the last message is a bot message with empty or non-empty content (indicator shows while stream hasn't started yet — hide once first token arrives by checking if last bot message has content)
- Actually, show TypingIndicator when `state.isStreaming` AND (messages is empty or last message role is 'user') — meaning the bot hasn't started its message yet
- Wait — better logic: Show TypingIndicator when `state.isStreaming` AND the most recent bot message (the one being streamed to) has empty content. Once first token arrives (content !== ''), hide indicator.
- Show StarterQuestions when `state.messageCount === 0` (no user messages yet)
- Auto-scroll to bottom: use a `useRef` on a sentinel div at the bottom, call `ref.current?.scrollIntoView({ behavior: 'smooth' })` in a useEffect that depends on `state.messages` length and the last message's content length (to scroll during streaming too)
- className: `chat-message-list`
- Use `overflow-y: auto` for scrolling

**5. MessageBubble.jsx** — Individual message

  - `isError === true` → `chat-bubble chat-bubble--error` (left-aligned, with retry button)
- For error messages: display content text + a "Retry" button that re-sends the last user message
- For limit messages: display the content (which includes contact info CTA)
- Render content as plain text (no markdown parsing — bot is configured to respond in plain text only)
