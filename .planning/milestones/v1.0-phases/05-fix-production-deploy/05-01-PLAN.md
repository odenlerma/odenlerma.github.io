<objective>
Inject VITE_PROXY_URL from GitHub Actions secrets into the deploy.yml build step so the production bundle uses the real Cloudflare Worker URL instead of localhost:8787. Add a pre-build validation step that fails CI if the secret is missing. Document the required secret setup.

Purpose: The deployed production bundle currently hardcodes `http://localhost:8787` as the API endpoint because `deploy.yml` runs `npm run build` without setting VITE_PROXY_URL. Vite bakes env vars at build time — without a system environment variable override, it falls back to the `.env` file's localhost value. This makes the chatbot non-functional on the live site.

Output: Two files updated — deploy.yml gets env injection + validation step, USER-SETUP.md gets VITE_PROXY_URL documentation. All existing chat requirements (CHAT-04, CHAT-05, CHAT-06, CHAT-08, COST-02) become reachable in production.
</objective>
