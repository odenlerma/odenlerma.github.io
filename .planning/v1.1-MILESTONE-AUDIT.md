## Tech Debt Summary

### Phase 8: Chatbot Visibility & Prominence (4 items)

1. **BOTTOM_NAV dead code** — Component and `getActiveSection()` function exist but are never rendered. Either render the component or remove the dead code.
2. **Duplicate welcome message ID** — Both InlineChat and ChatWindow dispatch `ADD_SYSTEM_MESSAGE` with `id: 'welcome'`. Guards prevent double-fire in practice, but identical IDs create fragile React key collision potential.
3. **Missing abort cleanup** — InlineChat should call `abort()` on unmount to cancel streaming when user scrolls away.
4. **No inline chat close/abort UI** — InlineChat lacks ChatHeader, so users can't explicitly abort a streaming response in the inline variant.

### Total: 4 items across 1 phase
