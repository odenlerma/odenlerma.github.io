## Tech Debt

### Phase 1: Infrastructure (2 items)
- `wrangler.toml` `namespace_id = "1001"` is a placeholder — replace with real Cloudflare Rate Limiting namespace ID before production deployment. The burst-tier rate limiter (`env.RATE_LIMITER.limit()`) will throw a runtime error without a valid namespace. The hourly in-memory limiter (30 req/hr) works independently as a fallback.
- Worker deployment requires manual Cloudflare account setup and `wrangler secret put DEEPSEEK_API_KEY` (documented in `01-USER-SETUP.md`)

### Phase 5: Fix Production Deploy (1 item)
- `VITE_PROXY_URL` and `CLOUDFLARE_API_TOKEN` GitHub repository secrets must be manually configured before production deploy works. deploy.yml includes a pre-build validation step that will fail CI with a clear error if `VITE_PROXY_URL` is missing.

### Total: 3 items across 2 phases

All items are deployment configuration requiring user action — no code defects, no stubs, no TODOs.
