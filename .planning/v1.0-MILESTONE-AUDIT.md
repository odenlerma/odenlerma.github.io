## Critical Gaps

### 1. Phase 3 Missing VERIFICATION.md (BLOCKER)

Phase 3 (Chat Widget) was executed (2 plans, 6 SUMMARY files exist) but never formally verified. No VERIFICATION.md exists at `.planning/phases/03-chat-widget/03-VERIFICATION.md`. This means all 12 Phase 3 requirements lack the verification source in the 3-source cross-reference.

### 2. CHAT-08: Error Display Broken (UNSATISFIED)

**Requirement:** Error message displayed on network/API failure with friendly retry prompt.

**Root cause:** `useChatApi.js` dispatches `SET_ERROR` with a string → stored in `state.error` → but **no component reads `state.error`**. Additionally, `MessageBubble.jsx` has a retry button gated on `msg.isError`, but `isError` is never set to `true` on any message object in the reducer. The error display and retry button are styled (`.chat-bubble--error` in style.scss) but are dead code paths.

**User impact:** When a network failure occurs, the typing indicator stops and the input re-enables, but the user sees silence — no error message, no retry option.

### 3. VITE_PROXY_URL Blocks Production (INTEGRATION GAP)

**Root cause:** `.env` contains `VITE_PROXY_URL=http://localhost:8787`. The GitHub Pages deploy workflow (`.github/workflows/deploy.yml`) runs `npm run build` without injecting a production URL. Vite bakes env vars at build time, so the deployed bundle will hardcode localhost as the API endpoint.

**User impact:** Every chat request on the live site will fail — the entire chatbot is non-functional in production.

**Fix:** Add `VITE_PROXY_URL` as a GitHub Actions secret and inject in deploy.yml:
```yaml
- run: npm run build
  env:
    VITE_PROXY_URL: ${{ secrets.VITE_PROXY_URL }}
```
