## Objective

Restyle the entire chat widget from dark theme to light theme by rewriting `src/components/chat/style.scss`. Replace all dark backgrounds, light-on-dark text, and dark-mode borders with the portfolio's cream/coral/blue palette. Apply glassmorphism treatments using existing mixins. No JSX changes — purely SCSS.

## Context

- **Single file change:** `src/components/chat/style.scss` (~296 lines)
- **Design system:** All tokens and mixins already exist in `custom.scss` (imported via `@import 'custom.scss'`)
- **Locked decisions:** See CONTEXT.md — every visual treatment is specified
- **BEM naming:** Existing `.chat-*` class structure stays the same

## Tasks

<task id="1" title="Restyle chat window panel and header" estimate="12min">

### What to change

**Chat Window Panel (`.chat-window`):**
- Replace `background: $dark` with `@include glassmorphism(20px, rgba(255, 245, 227, 0.85))` — heavy frosted cream
- Replace `box-shadow: 0 8px 40px rgba(0, 0, 0, 0.3)` with `box-shadow: 0 8px 40px rgba(48, 48, 54, 0.12)` — lighter shadow for light theme
- Change `color: $light` to `color: $dark` — dark text on light background
- Mobile responsive block (`@media max-width: 768px`): keep the same layout rules, just inherit the new background and color (RESP-02)

**Chat Header (`.chat-header`):**
- Replace `background: lighten($dark, 5%)` with `background: rgba(255, 245, 227, 0.92)` — slightly more opaque cream than the panel (creates subtle depth)
- Replace `border-bottom: 1px solid rgba(255, 255, 255, 0.1)` with a gradient accent line:
  ```scss
  border-bottom: none;
  position: relative;
  &::after {
    content: '';
    position: absolute;
    bottom: 0;
    left: 0;
    right: 0;
    height: 2px;
    background: linear-gradient(90deg, $primary, $secondary);
  }
  ```
- `.chat-header__avatar`: Keep as-is (coral-to-blue gradient already correct)
- `.chat-header__name`: Apply `@include gradient-text` for coral-to-blue name text
- `.chat-header__close`:
  - Change `color: rgba($light, 0.6)` to `color: rgba($dark, 0.5)`
  - Change hover `color: $light` to `color: $dark`
  - Change hover `background: rgba(255, 255, 255, 0.1)` to `background: rgba($dark, 0.08)`

### Verification

- [ ] Chat window background is frosted cream glass, not `$dark`
- [ ] Header is slightly more opaque cream than body area
- [ ] Gradient accent line (coral-to-blue) visible at bottom of header
- [ ] "Audy" name displays gradient text
- [ ] Close button is dark on light, not light on dark
- [ ] No `$dark` used as background anywhere in window or header
- [ ] Mobile layout still works (full-screen takeover, RESP-02)

</task>

## Must-Haves (Goal-Backward Verification)

Derived from phase goal: "The chat widget fully reflects the portfolio's light design system — cream backgrounds, coral/blue accents, glassmorphism bot bubbles, no trace of dark mode"

1. **Zero dark backgrounds** — No `$dark` used as a background color, no `lighten($dark, N%)` backgrounds anywhere in `style.scss`
2. **Cream glass panel** — Chat window uses glassmorphism with cream tint (`rgba(255,245,227, 0.85)`)
3. **Dark text on light** — All text uses `$dark` or dark-derived colors (not `$light` or white, except user bubble)
4. **Glass bot bubbles** — Bot/error/limit bubbles use `backdrop-filter: blur()` with white translucent background
5. **Gradient accents** — Header has coral-to-blue gradient line, "Audy" name uses `gradient-text` mixin
6. **Light input area** — Input field, container, and borders all use light-theme colors
7. **Themed starters** — Starter chips use `$secondary` text on light blue tint
8. **Themed typing indicator** — Glass bubble with gradient-colored dots
9. **Responsive preserved** — Mobile 768px breakpoint still works with new theme (RESP-02)
10. **No dark-mode artifacts** — Zero instances of: `lighten($dark, ...)`, `rgba(255,255,255, 0.1)` as border on dark bg, `rgba($light, ...)` as text color
