## Objective

Make the floating chat FAB larger, more prominent, and add a pulse/glow animation that draws visitor attention. The glow stops after the user has interacted with the chat at least once.

## Context

- **Phase Goal:** The chatbot is the highlight of the portfolio — visitors encounter a dedicated "Ask My AI" section while scrolling and can always reach the chat via a prominent, attention-drawing FAB.
- **Locked decisions from CONTEXT.md:** Subtle pulse glow using coral-to-blue gradient shadow; glow stops after user opens chat once; no glow when chat is open (X icon); icon only, no text; size is Claude's discretion (larger than 56px/48px).
- **Current FAB:** 56px desktop / 48px mobile, gradient background, fixed bottom-right, hover-lift mixin.

**Step 2: Update `src/components/chat/ChatFab.jsx`**

Replace the entire component with:
```jsx
import { motion } from 'framer-motion';
import { useChat } from '@/context/ChatContext';

const ChatFab = () => {
  const { state, dispatch } = useChat();

  // Glow only when chat is closed AND user hasn't interacted yet
  const showGlow = !state.isOpen && !state.hasInteracted;

  return (
    <motion.button
      className={`chat-fab${showGlow ? ' chat-fab--glow' : ''}`}
      onClick={() => dispatch({ type: 'TOGGLE_OPEN' })}
      whileHover={{ scale: 1.1 }}
      whileTap={{ scale: 0.9 }}
      aria-label={state.isOpen ? 'Close chat' : 'Open chat'}
    >
      <i className={`bi ${state.isOpen ? 'bi-x-lg' : 'bi-chat-dots-fill'}`} />
    </motion.button>
  );
};

export default ChatFab;
```

Key change: conditional `chat-fab--glow` class based on `!state.isOpen && !state.hasInteracted`.
