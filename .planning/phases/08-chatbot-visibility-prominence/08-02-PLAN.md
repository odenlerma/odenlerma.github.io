## Objective

Make the floating chat FAB larger, more prominent, and add a pulse/glow animation that draws visitor attention. The glow stops after the user has interacted with the chat at least once.

## Context

**Phase Goal:** The chatbot is the highlight of the portfolio — visitors encounter a dedicated "Ask My AI" section while scrolling and can always reach the chat via a prominent, attention-drawing FAB.

**CONTEXT.md locked decisions:**
- Subtle pulse glow animation using coral-to-blue gradient shadow
- Glow stops after user has interacted (opened chat at least once)
- No glow when chat is open (X icon state) — only animates when closed
- Icon only, no text label on the FAB
- FAB size: larger than current 56px/48px (Claude's discretion — pick prominent but not obnoxious)

**Current FAB:** 56px desktop / 48px mobile, positioned fixed bottom-right, gradient background, no animation beyond hover-lift.

## must_haves

1. FAB is visibly larger than the previous 56px desktop / 48px mobile sizes
2. FAB has a pulse/glow animation that uses the coral-to-blue gradient colors
3. Glow animation stops after the user has opened the chat at least once
4. FAB remains accessible and correctly positioned at all scroll depths
5. No glow when chat is open (showing X icon)

## Tasks

<task id="1" title="Add hasInteracted state to ChatContext">

**What:** Track whether the user has ever opened the chat, so the FAB can conditionally show the glow animation.

**Files:** `src/context/ChatContext.jsx`

**Steps:**

1. Read `src/context/ChatContext.jsx`

2. Add `hasInteracted: false` to `initialState`:
   ```js
   const initialState = {
     messages: [],
     isStreaming: false,
     error: null,
     messageCount: 0,
     isOpen: false,
     hasInteracted: false,  // NEW: true after first chat open
   };
   ```

3. Update the `TOGGLE_OPEN` case in `chatReducer`:
   ```js
   case 'TOGGLE_OPEN':
     return {
       ...state,
       isOpen: !state.isOpen,
       hasInteracted: state.hasInteracted || !state.isOpen,
       // If toggling open (!state.isOpen means it's about to open), set hasInteracted
     };
   ```

4. Update the `SET_OPEN` case similarly:
   ```js
   case 'SET_OPEN':
     return {
       ...state,
       isOpen: action.payload,
       hasInteracted: state.hasInteracted || action.payload,
     };
   ```

**Acceptance:** `state.hasInteracted` is `false` initially, becomes `true` permanently after the user opens the chat for the first time.

</task>

<task id="2" title="Upgrade FAB size and add pulse glow animation">

**What:** Increase FAB dimensions, add CSS keyframe pulse/glow animation, and conditionally apply it based on chat state.

**Files:** `src/components/chat/ChatFab.jsx`, `src/components/chat/style.scss`

**Steps:**

1. Read `src/components/chat/ChatFab.jsx` and the `.chat-fab` section in `src/components/chat/style.scss`

2. Update `.chat-fab` in `style.scss`:
   - Increase size from 56px to 68px desktop, 48px to 56px mobile
   - Increase font-size proportionally (1.5rem -> 1.75rem desktop, 1.25rem -> 1.4rem mobile)
   - Add pulse glow keyframes:
   ```scss
   // ─── FAB Pulse Glow Animation ─────────────────────────────────────────
   @keyframes fab-pulse-glow {
     0%, 100% {
       box-shadow: 0 4px 20px rgba($primary, 0.4);
     }
     50% {
       box-shadow: 0 4px 20px rgba($primary, 0.5),
                   0 0 30px rgba($primary, 0.3),
                   0 0 60px rgba($secondary, 0.15);
     }
   }

   .chat-fab {
     // ... existing styles with updated sizes
     width: 68px;
     height: 68px;
     font-size: 1.75rem;

     &--glow {
       animation: fab-pulse-glow 2.5s ease-in-out infinite;
     }

     @media (max-width: 768px) {
       width: 56px;
       height: 56px;
       font-size: 1.4rem;
     }
   }
   ```

3. Update `ChatFab.jsx` to conditionally apply the glow class:
   ```jsx
   const ChatFab = () => {
     const { state, dispatch } = useChat();

     // Show glow only when: chat is closed AND user hasn't interacted yet
     const showGlow = !state.isOpen && !state.hasInteracted;

     return (
       <motion.button
         className={`chat-fab ${showGlow ? 'chat-fab--glow' : ''}`}
         onClick={() => dispatch({ type: 'TOGGLE_OPEN' })}
         whileHover={{ scale: 1.1 }}
         whileTap={{ scale: 0.9 }}
         aria-label={state.isOpen ? 'Close chat' : 'Open chat'}
       >
         <i className={`bi ${state.isOpen ? 'bi-x-lg' : 'bi-chat-dots-fill'}`} />
       </motion.button>
     );
   };
   ```

4. Verify: FAB should be visibly larger, glow animation pulses when chat hasn't been opened, glow stops after first open, no glow when chat panel is showing.

**Acceptance:** FAB is 68px/56px, glow animates before first interaction, stops permanently after, never shows when chat is open.

</task>
