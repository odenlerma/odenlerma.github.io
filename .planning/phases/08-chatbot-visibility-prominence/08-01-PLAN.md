## Objective

Create the dedicated "Ask My AI" scroll section with a functional embedded chat interface, shared conversation state between section and floating widget, scroll-tracked bottom nav entry, and framer-motion entrance animation.

## Context

**Phase Goal:** The chatbot is the highlight of the portfolio — visitors encounter a dedicated "Ask My AI" section while scrolling and can always reach the chat via a prominent, attention-drawing FAB.

**CONTEXT.md locked decisions:**
- Section placement: Intro -> Works -> About -> Ask My AI -> Footer
- Fully functional inline chat sharing ChatProvider context with floating widget
- Same starter question pills as floating widget
- Centered single-column layout; playful bold headline; gradient text headline
- Staggered fade-up entrance via framer-motion (~0.15s stagger delay)
- Content-sized section (not full viewport height)
- No auto-open of floating widget when scrolling away from the section

## must_haves

Goal-backward derived — if ANY is missing, the phase goal fails:

1. A `<section>` with id="ask-ai" appears in HomePage between About and Footer
2. The section contains a headline, description, and a fully functional inline chat (send messages, get responses)
3. Conversation state is shared — a message sent in the section chat appears if the user opens the floating widget
4. The section is scroll-tracked in the bottom nav as a 4th entry
5. Framer-motion staggered fade-up entrance animation triggers on scroll into view
6. Mobile layout adapts cleanly without overflow

<task id="2" title="Create InlineChat component and AskAiLayout">

**What:** Build the inline chat component and the section layout with headline, description, and embedded chat.

**Files:** `src/components/chat/InlineChat.jsx`, `src/layouts/AskAiLayout/index.jsx`, `src/components/chat/style.scss`

**Steps:**

1. Create `src/components/chat/InlineChat.jsx`:
   - Import `useChat` from `@/context/ChatContext`
   - Import `MessageList`, `ChatInput` from sibling components
   - Import `{ useEffect, useRef }` from react
   - This component renders a static (non-floating) chat interface:
   ```jsx
   const InlineChat = () => {
     const { state, dispatch } = useChat();
     const hasWelcomed = useRef(false);

     // Dispatch welcome message on first render if no messages exist
     useEffect(() => {
       if (!hasWelcomed.current && state.messages.length === 0) {
         hasWelcomed.current = true;
         dispatch({
           type: 'ADD_SYSTEM_MESSAGE',
           payload: {
             id: 'welcome',
             content: "Hi! I'm Audy, Audruey's AI assistant. Ask me anything about her experience, skills, or projects.",
             isLimit: false,
           },
         });
       }
     }, [state.messages.length, dispatch]);

     return (
       <div className="inline-chat">
         <MessageList />
         <ChatInput />
       </div>
     );
   };
   ```
   - The welcome message logic is similar to ChatWindow but triggers immediately (not gated on `isOpen`)

2. Create `src/layouts/AskAiLayout/index.jsx`:
   - Import `{ motion }` from framer-motion
   - Import `{ Container, Row, Col }` from react-bootstrap
   - Import `InlineChat` from `@components/chat/InlineChat`
   - Use staggered fade-up animation with framer-motion:
   ```jsx
   const containerVariants = {
     hidden: {},
     visible: {
       transition: { staggerChildren: 0.15 },
     },
   };

   const itemVariants = {
     hidden: { opacity: 0, y: 40 },
     visible: {
       opacity: 1,
       y: 0,
       transition: { duration: 0.6, ease: [0.25, 0.46, 0.45, 0.94] },
     },
   };
   ```
   - Layout structure (centered single-column):
   ```jsx
   const AskAiLayout = () => (
     <motion.div
       variants={containerVariants}
       initial="hidden"
       whileInView="visible"
       viewport={{ once: true, amount: 0.2 }}
     >
       <Container>
         <Row className="justify-content-center">
           <Col xs={12} md={10} lg={8} className="text-center">
             <motion.h2
               className="ask-ai__headline"
               variants={itemVariants}
             >
               I trained an AI on my entire career. Try it.
             </motion.h2>
             <motion.p
               className="ask-ai__description"
               variants={itemVariants}
             >
               Go ahead — ask about my projects, tech stack, experience, or anything else. Audy knows it all.
             </motion.p>
           </Col>
         </Row>
         <Row className="justify-content-center">
           <Col xs={12} md={10} lg={8}>
             <motion.div variants={itemVariants}>
               <InlineChat />
             </motion.div>
           </Col>
         </Row>
       </Container>
     </motion.div>
   ```
