## Objective

Create the dedicated "Ask My AI" scroll section with a functional embedded chat interface, shared conversation state between section and floating widget, scroll-tracked bottom nav entry, and framer-motion entrance animation.

## Context

- **Phase Goal:** The chatbot is the highlight of the portfolio — visitors encounter a dedicated "Ask My AI" section while scrolling and can always reach the chat via a prominent, attention-drawing FAB.
- **Locked decisions from CONTEXT.md:** Section goes after About (Intro -> Works -> About -> Ask My AI -> Footer); fully functional inline chat sharing ChatProvider; same starter pills; centered single-column layout; playful bold headline with gradient text; staggered fade-up ~0.15s via framer-motion; content-sized section (not full viewport); no auto-open of floating widget when scrolling away.
- **Current architecture:** `ChatProvider` wraps only `CHAT_WIDGET` in `src/components/chat/index.jsx`. Must be lifted to `App.jsx` so inline chat and floating widget share conversation state.

**Step 3: Create `src/components/chat/InlineChat.jsx`**
- Import `{ useEffect, useRef }` from react
- Import `useChat` from `@/context/ChatContext`
- Import `MessageList` from `./MessageList`
- Import `ChatInput` from `./ChatInput`
- Create `InlineChat` component that renders a static (non-floating) chat:
  ```jsx
  const InlineChat = () => {
    const { state, dispatch } = useChat();
    const hasWelcomed = useRef(false);

    useEffect(() => {
      if (!hasWelcomed.current && state.messages.length === 0) {
        hasWelcomed.current = true;
        dispatch({
          type: 'ADD_SYSTEM_MESSAGE',
          payload: {
            id: 'welcome',
            content: "Hi! I'm Audy, Audruey's AI assistant. Ask me anything about her experience, skills, or projects.",
            isLimit: false,
          },
        });
      }
    }, [state.messages.length, dispatch]);

    return (
      <div className="inline-chat">
        <MessageList />
        <ChatInput />
      </div>
    );
  };
  ```
- The welcome message triggers immediately (not gated on `isOpen` like ChatWindow)
- Export default `InlineChat`

## Must-Haves (Goal-Backward Verification)

Derived from phase goal: "The chatbot is the highlight of the portfolio — visitors encounter a dedicated 'Ask My AI' section while scrolling and can always reach the chat via a prominent, attention-drawing FAB"

1. **Section exists in page flow** — A `<section id="ask-ai">` with `useInView` tracking appears between About and Footer

6. **Mobile responsive** — Section padding, chat height (420px), and layout adapt for screens <=768px
7. **No broken floating widget** — ChatProvider lift doesn't break existing FAB/ChatWindow functionality
