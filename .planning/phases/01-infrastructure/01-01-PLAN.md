<task type="checkpoint:human-action" gate="blocking">
  <action>Set up Cloudflare account and configure DeepSeek API key</action>
  <instructions>
  Before the Worker can be deployed, you need:

  1. **Cloudflare Account** (if you don't have one):
     - Go to https://dash.cloudflare.com/sign-up
     - Create a free account

  2. **Cloudflare API Token** (for GitHub Actions deployment):
     - Go to https://dash.cloudflare.com/profile/api-tokens
     - Click "Create Token"
     - Use the "Edit Cloudflare Workers" template
     - Copy the token
     - Add it as a GitHub repo secret: Settings -> Secrets and variables -> Actions -> New repository secret
     - Name: `CLOUDFLARE_API_TOKEN`, Value: the token you copied

  3. **DeepSeek API Key as Worker Secret**:
     - From the `workers/chat-proxy/` directory, run:
       ```
       npx wrangler secret put DEEPSEEK_API_KEY
       ```
     - Paste your DeepSeek API key when prompted
     - (This requires Cloudflare login — wrangler will open a browser auth flow)

  4. **Local .dev.vars**:
     - Edit `workers/chat-proxy/.dev.vars` and replace the placeholder with your real DeepSeek API key

  5. **Verify DeepSeek API access** (quick curl test):
     ```
     curl -s https://api.deepseek.com/v1/chat/completions \
       -H "Content-Type: application/json" \
       -H "Authorization: Bearer YOUR_DEEPSEEK_API_KEY" \
       -d '{"model":"deepseek-chat","messages":[{"role":"user","content":"Say hello"}],"max_tokens":10}' | head -c 200
     ```
     You should see a JSON response with a "choices" array — not an error.
  </instructions>
  <resume-signal>Type "done" when all setup is complete (Cloudflare account, API token as GitHub secret, wrangler secret set, .dev.vars updated, DeepSeek API verified)</resume-signal>
</task>
